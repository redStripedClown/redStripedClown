## About me

I'm a student at the **Federal Institute of Paraná (IFPR)**, completing a technical program in **Systems Development** integrated with high school.

Most of my work so far has been around children — teaching jiu-jitsu, volunteering at kids' events, building accessible educational tools — and that shaped how I build: practical, careful, and a little bit playful.

I'm interested in software development, assistive technology, and the intersection of software and hardware. I also run [**Outro Lado da Lua**](https://github.com/OutroLadoDaLua), a GitHub organization for game-jam and collaborative projects, so that work has a shared home instead of sitting under a single account.

> *The clown's for the kids. The code's for everyone.*
