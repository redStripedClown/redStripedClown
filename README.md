## 🚀 Featured Projects

### 🐾 [Caonectados](https://github.com/CaoNectados/Caonectados)

A collaborative system designed to support the animal adoption process, connecting adopters, animal rescuers, and organizations. My work includes requirements analysis, data modeling, software development, and feature integration.

**Technologies:** PHP, JavaScript, SQL, and web development tools.

### 🫀 [Tactile and Audio Cardiovascular System](https://github.com/Sistema-Cardiovascular-Biologia-Tatil/tocador_audio)

An assistive educational project combining tactile interaction and responsive audio to make cardiovascular anatomy more accessible. I contributed to the audio system's programming, prototype assembly, research, and audio description script.

**Technologies:** Arduino, C++, SD card and audio modules, 3D modeling, and prototyping.

Presented at FICIÊNCIAS and IFTECH in 2025.

3D modeling resources developed as part of the tactile and audio cardiovascular educational project.
