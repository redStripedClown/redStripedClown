## 🌷 About me

I'm a student at the **Federal Institute of Paraná (IFPR)**, completing a technical program in **Systems Development** integrated with high school.

Most of my work so far has been around children — teaching jiu-jitsu, volunteering at kids' events, building accessible educational tools — and that's shaped how I build: practical, careful, and a little bit playful.

I'm interested in software development, assistive technology, and the intersection between software and hardware. I also run [**Outro Lado da Lua**](https://github.com/OutroLadoDaLua), a GitHub org for game-jam and collaborative projects, so that work has a shared home rather than sitting under a single account.

> *The clown's for the kids. The code's for everyone.*
